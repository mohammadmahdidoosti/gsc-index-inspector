=== GSC Index Inspector ===
Requires at least: 5.8
Requires PHP: 7.4
Stable tag: 1.5.0
License: GPL-2.0-or-later

بررسی وضعیت ایندکس صفحات با Google Search Console URL Inspection API — بدون Composer و کتابخانه‌ی جانبی.

== امکانات ==
* منوی مستقل «ایندکس گوگل» با داشبورد، بررسی گروهی و تنظیمات
* داشبورد: جست‌وجوی سریع هر آدرس، کارت‌های آمار، نوار پوشش ایندکس و بررسی‌های اخیر
* نتیجه به‌صورت چک‌لیست خوانا: robots.txt، دریافت صفحه، noindex، تطابق canonical، سایت‌مپ
* ستون «ایندکس گوگل» + فیلتر وضعیت + کار دسته‌جمعی در لیست نوشته‌ها و برگه‌ها
* متاباکس در ویرایشگر نوشته
* ترتیب هوشمند صف: بررسی‌نشده‌ها ← ایندکس‌نشده‌ها ← تازه ویرایش‌شده‌ها ← به‌روزرسانی بقیه، با امکان انتخاب انواع محتوای مهم‌تر
* بررسی گروهی با WP-Cron یا «اجرای سریع در مرورگر» با نوار پیشرفت زنده
* کنترل سهمیه‌ی ۲۰۰۰/روز، کش نتایج، توقف خودکار صف در خطای احراز هویت یا سهمیه
* راه‌اندازی مرحله‌ای: بارگذاری فایل JSON با کشیدن و رها کردن، پیشنهاد Property، تست اتصال
* خروجی CSV/TXT و کپی آدرس‌های ایندکس‌نشده برای ارسال به افزونه‌های Indexing API
* افزودن خودکار به صف: هنگام انتشار/ویرایش محصول و اسکن روزانه (دسته‌هایی که تازه محصول گرفته‌اند، بررسی‌نشده‌ها، ایندکس‌نشده‌ها و ایندکس‌شده‌های قدیمی)
* واکنش‌گرا (موبایل) و راست‌به‌چپ

== نصب ==
1. پیشخوان ← افزونه‌ها ← افزودن ← بارگذاری افزونه ← فایل zip را انتخاب و فعال کنید.
2. منوی «ایندکس گوگل» به‌طور خودکار شما را به مراحل راه‌اندازی می‌برد.
3. در Google Cloud یک پروژه بسازید و Google Search Console API را فعال کنید.
4. یک Service Account بسازید و کلید JSON آن را دانلود و در تنظیمات افزونه رها کنید.
5. ایمیل Service Account را در Search Console ← Settings ← Users and permissions اضافه کنید.
6. Property را وارد، ذخیره و «تست اتصال» را بزنید.

روش امن‌تر برای کلید (به‌جای ذخیره در دیتابیس):
define( 'GSCII_SERVICE_ACCOUNT_FILE', '/path/outside/public_html/gsc-key.json' );

== فرمت Property ==
* Domain property:     sc-domain:example.com
* URL-prefix property: https://example.com/

== محدودیت‌های گوگل ==
* ۲۰۰۰ درخواست در روز و ۶۰۰ در دقیقه برای هر Property
* این API فقط وضعیت را می‌خواند؛ درخواست ایندکس (Request Indexing) از طریق API عمومی ممکن نیست.

== رفع خطا ==
* 403 Permission denied: ایمیل Service Account به Property اضافه نشده یا Property اشتباه وارد شده.
* invalid_grant: ساعت سرور نادرست است یا کلید حذف/باطل شده.
* 429: سهمیه تمام شده.

== تغییرات ==
= 1.5.0 =
* افزودن خودکار به صف هنگام انتشار/ویرایش نوشته یا محصول، همراه با دسته‌ها و دسته‌های والد
* اسکن روزانه‌ی خودکار و دکمه‌ی «اسکن همین الان»
* تنظیم فاصله‌ی بررسی دوباره‌ی صفحات ایندکس‌شده (پیش‌فرض ۳۰ روز)؛ ایندکس‌نشده‌ها هر ۳ روز

= 1.4.1 =
* رفع: دسته‌های والدی که محصولاتشان در زیردسته‌ها است (count=0) نادیده گرفته می‌شدند؛ حالا تعداد با احتساب زیردسته‌ها حساب می‌شود
* گزینه‌ی «بررسی دسته‌های خالی هم» در تنظیمات
* رفع: شمارنده‌ی سهمیه بر اساس روز UTC بود؛ حالا مثل گوگل نیمه‌شب به وقت Pacific ریست می‌شود و زمان شارژ نمایش داده می‌شود
* با خطای 429 روزانه از گوگل، شمارنده با گوگل هم‌گام می‌شود و صف تا زمان شارژ صبر می‌کند

= 1.4.0 =
* تب «خروجی»: CSV کامل (سازگار با اکسل)، TXT و کپی آدرس‌ها بر اساس وضعیت، با فیلتر صفحات غیرقابل ایندکس و سقف تعداد
* کارت «ایندکس نشده» در داشبورد حالا «خارج از ایندکس» (URL is unknown to Google) را هم می‌شمارد و دسته‌بندی‌ها هم در آمار حساب می‌شوند
* کلیک روی کارت‌های آمار مستقیم به خروجی همان وضعیت می‌رود

= 1.3.0 =
* بررسی صفحات دسته‌بندی (مثل دسته‌بندی محصولات ووکامرس) با ستون وضعیت و کار دسته‌جمعی
* گزینه‌ی «اول دسته‌بندی‌ها، بعد محتوا»؛ دسته‌های پرمحصول‌تر جلوتر

= 1.2.0 =
* اولویت‌بندی هوشمند صف بررسی گروهی (چهار سطح) و انتخاب انواع محتوای مهم‌تر
* نمایش ترتیب و نوبت‌های بعدی صف در تب بررسی گروهی

= 1.1.0 =
* بازطراحی کامل رابط کاربری و منوی مستقل
* رفع باگ خراب شدن private_key هنگام ذخیره از فرم تنظیمات
* صف در خطاهای احراز هویت/شبکه/سهمیه متوقف می‌شود و صفحات را از دست نمی‌دهد
* درخواست‌های ناموفق پیش از ارسال به گوگل در سهمیه شمرده نمی‌شوند
* استفاده از کش برای آدرس‌هایی که به یک نوشته تعلق دارند
